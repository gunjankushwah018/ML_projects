deployed using Streamlit.

##  About the Project

In this project, I used content-based filtering to
recommend movies that are similar to the movie selected
by the user.

The system uses cosine similarity to find movies with
similar features.

When a user selects a movie, the application displays
a list of recommended movies along with their posters.

##  Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Cosine Similarity
- TMDB API

##  How It Works

1. Movie data is loaded and processed.
2. Relevant movie features are combined.
3. Cosine similarity is used to calculate movie
   similarity.
4. When a user selects a movie, similar movies
   are recommended.
5. Movie posters are fetched using the TMDB API.

##  Features

- Select a movie from the dropdown.
- Get similar movie recommendations.
- Display movie posters.
- Simple and interactive Streamlit interface.
