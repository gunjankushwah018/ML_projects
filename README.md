# Machine Learning Projects

This repository contains some of my machine learning projects that I built while learning and practicing machine learning.

## Projects

### 🎬 Movie Recommendation System

A movie recommendation system that recommends similar movies based on the movie selected by the user.

The project uses a **content-based recommendation approach**, where movie information is processed and similarity between movies is calculated to find relevant recommendations. The recommendations are displayed through a simple **Streamlit web app**, and movie posters are fetched using the **TMDB API**.

**Tech Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Pickle
* TMDB API
* Content-Based Filtering
* Cosine Similarity

### 📧 Email Spam Classifier

An email spam classifier that predicts whether a given message is **Spam** or **Ham (Not Spam)**.

The project uses text preprocessing and machine learning techniques to convert text into numerical features and classify messages. It also includes a Streamlit app for testing messages.

**Tech Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* TF-IDF Vectorization
* Multinomial Naive Bayes
* Streamlit
* NLP / Text Processing
